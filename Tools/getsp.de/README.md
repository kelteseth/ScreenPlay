# ScreenPlay Releases Website
A simple PHP website that displays ScreenPlay releases with download links and checksums.

### Setup
1. Install php and restat the terminal:
   ```cmd
    winget install PHP.PHP.8.1
   ```
1. Start the PHP development server:
   ```cmd
   php.exe -S 127.0.0.1:8080 -t .
   ```
1. Open your browser and go to:
   ```
   http://127.0.0.1:8080
   ```
